Water that actually flows

Drop a water block and mark tiles with ~. The engine renders animated waves, sky reflections and moving specular highlights into the floor casting pipeline — then slows you down, splashes, and tints the screen while you swim. Torches, crystals and glowing enemies cast real flickering light onto every wall and floor pixel.

  • wave — swell amplitude
  • reflect — sky reflection
  • fogcolor — atmospheric tint
  • ceiling off — open sky + stars
  • detail — render resolution
  • glow on — light-emitting sprites
Try the Water Temple preset →
water-temple.votyer 
water {
    color #1a6f92
    wave 0.55
    reflect 0.7
}

item "torch" {
    char "t"
    shape torch
    color #ff9f43
    pickup off   // decor, stays put
    glow on      // emits real light
}

rules {
    on enter water { sound splash }
    on all items taken { unlock exit }
    on reach exit { win }
}

Eight superpowers, in the box

votyer v1.1 handles rendering, liquids, light, physics, audio and game flow — you write the fun part.

≈

Animated water

Per-pixel wave distortion, sky reflection, caustic shimmer and splash physics on any ~ tile — three lines of script.

✦

Dynamic lights

Glowing sprites become real light sources with distance falloff and torch flicker, baked into the textured raycaster.

▣

Textured raycasting

Procedural brick, block and panel textures generated from your palette — floor and ceiling casting included. ceiling off opens the sky.

✦

15 built-in sprites

Crystals, coins, torches, ghosts, robots — procedurally drawn with tintable colors, ground shadows and glow. See the sprite gallery.

Audio synthesizer

Physics & collision

Events & rules

NEW LANGUAGE — E#

Now the same family builds entire websites

E# (.e# files) compiles to pure HTML, CSS and JavaScript: hero sections, feature grids, gradient galleries, stats bands, quotes, code windows, footers — with galaxy particle backgrounds and votyer games embedded inline. One language for your game, one for your site.

Compile a site now → Read the E# docs →
site.e# 
site "Nova" {
  theme { accent #7c6cff }
  hero {
    title "Feel alive."
    galaxy on
  }
  features "What I do" {
    item "Interfaces" "Systems."
  }
  game { preset water-temple }
}
