<script src="votyer.js"></script>
<script type="text/votyer">
game "Star Vault" {
    size 960 540
    sky #101426
    fog 0.5
}

map {
    "############"
    "#P...#.....#"
    "#.#C.#.###.#"
    "#...#.G.#..#"
    "############"
}

item "gem" {
    char "C"
    shape crystal
    color #5eead4
    on take {
        score += 50
        sound pickup
        say "Gem secured!"
    }
}

rules {
    on all items taken { unlock exit }
    on reach exit      { win }
}

on start { say "Find the gem. Reach the portal." }
</script>

A game is

No build step. No npm. No boilerplate. Drop votyer.js into any HTML5 page, write your world in the votyer language, and the engine compiles it live in the browser.

The parser, interpreter, raycaster, sprite factory, physics and synthesizer are all inside one 100 KB file.

Everything a retro FPS needs, in the box

votyer handles rendering, physics, audio and game flow so you only write the fun part.

◆

Retro raycasting engine

A DDA raycaster renders true first-person 3D corridors at 60 fps — textured walls, distance fog, head-bob and screen shake included.

✦

Sprites, items & pickups

Billboarded sprites with depth sorting and procedural pixel-art shapes — crystal, ghost, robot, orb and more. No image files needed.

♪

Audio synthesizer

Ten chiptune sound effects generated live with WebAudio — sound pickup, sound win, sound denied — zero audio assets.

⚙

Physics & collision

Circle-vs-grid sliding collision, knockback, acceleration constants and invulnerability frames — tuned for that classic 90s feel.

⚡

Events & rules

Reactive game logic: on take, on touch enemy, on all items taken, on reach exit — write the rules, the engine fires them.

★

Menus & HUD

Title screen, pause, win/lose screens, health bar, score, minimap and message toasts render automatically from your script.

Up and running in three moves

Everything happens in the browser — the language compiles at runtime.

STEP 01

Add the runtime

One <script src="votyer.js"> tag. Works from a file, a server or GitHub Pages.

STEP 02

Write votyer

Describe your game, draw the map, place items and enemys, and wire up rules.

STEP 03

Open the page

The engine parses, compiles and boots your game into a menu — click to play. That's it.
